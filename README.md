🧘‍♀️ YogAarogya
YogAarogya is a wellness-focused web platform designed to help users explore personalized yoga practices based on their health conditions. Built using React, TypeScript, Vite, and Supabase, it offers a clean and responsive interface to enhance the user’s wellness journey.
🌟 Features
🧠 Yoga Questionnaire: Get personalized asana recommendations based on selected health issues.
📊 Dashboard: Visual insights into user data with charts (powered by Chart.js).
👥 Authentication: User login and signup system integrated with Supabase.
📱 Responsive Design: Optimized for mobile, tablet, and desktop use.
🚀 Tech Stack
Frontend: React, TypeScript, Vite
Backend: Supabase (Database + Auth)
Charts: Chart.js
Styling: CSS Modules (or your custom CSS)
